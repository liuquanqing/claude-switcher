# Claude Switcher 1.3.8 RC8

同时包含 RC7 的全部修复与「同步会话」升级。

Fixes missing menu bar quota percentage for accounts without a 5-hour usage window by falling back to weekly limits (matching the account card's metric priority). Includes all fixes and Session Sync upgrades from RC7.
