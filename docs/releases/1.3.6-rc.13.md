# Claude Switcher 1.3.6 RC13

- 从切换器打开默认或独立终端时，先核验本机代理出口，再用该代理启动 Claude Code。出口检查失败时不打开终端。
- 优先复用与桌面账号相符的默认 CLI。默认 CLI 确认未登录时，即使存在旧备份，也可选择在默认终端登录；旧备份恢复失败会返回选择页。
- 正常的终端与保护状态合成一行，核对细节留在详情。检查软件更新移回齿轮菜单，与预览更新选项放在一起。

**Apple Silicon · macOS 13+ · 预览版。** 已安装较早预览版的用户可在齿轮菜单启用「接收预览更新」，再选择「检查更新」。

The terminal launcher now uses the checked local proxy for both default and separate profiles. It prefers a matching default login and keeps official sign-in available when an old backup cannot be restored. The main panel is more compact, and software updates are back in Settings.
