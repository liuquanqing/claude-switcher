# Claude Switcher 1.3.8 RC6

修复后台静默轮询偶发弹出 macOS 钥匙串密码框的问题：后台自动刷新不再读取由 Claude Code CLI 写入传统登录钥匙串的 `Claude Code-credentials`，CLI 凭据备份仅在切换账号、连接终端或手动触发时执行，桌面订阅额度自动刷新不受影响。

精简软件更新弹窗下载态界面，去掉冗余的「下载进度」文案，改为单行进度条加右侧百分比。

Fixes unexpected background macOS Keychain password prompts by removing automatic polling reads of `Claude Code-credentials` (CLI backup now runs only on explicit user actions). Simplifies the Software Update download progress card to a single bar + percentage row.

Apple Silicon · macOS 13+
