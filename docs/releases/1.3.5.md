## 本版更新

- **额度静默自动更新**：当前订阅在使用中约每 5 分钟更新，闲置时约每 15 分钟。打开面板、系统唤醒和账号变化时按数据年龄补查，不必反复手动刷新。
- **及时发现本地换号**：每 15 秒轻量观察本地身份，不产生网络流量。发现桌面身份变化后撤下旧的当前身份及 CLI 一致结论，重新确认后再更新。
- **后台不弹授权**：自动读取拿不到系统许可时保留缓存；底部手动刷新继续走官方 CLI，必要时由用户完成系统授权。不自动续期或改写登录。
- **旧数据如实保留**：失败不会清空额度或伪造“刚刚更新”；限流遵守服务端等待时间，避免连续请求。兼容仅提供周额度、没有五小时窗口的订阅。

自动查询只处理当前完整匹配的订阅身份；其他账号保留各自历史缓存。API 模式下也只展示可确认的订阅额度，不是 API 余额。查询前后核对磁盘当前账号、实际模式、完整身份和 token；期间变化的旧结果不提交。

## 验证与边界

202 项核心测试、237 项 controller/store 隔离检查和发布模式构建通过，使用虚构账号、模拟 HTTP 回应与临时目录。GitHub 当前拒绝启动工作流（HTTP 422：Actions has been disabled for this repository），云端 CI 未运行，不计为通过。

本版没有改变守卫策略，也没有新增网络层阻断能力。安装只更新切换器界面，原有守卫可继续运行；现有 Claude 和 CLI 任务、登录、会话及代理配置不由安装器操作。

自动路径低频、只读且不弹窗，仍会发送携带访问凭据的额度请求，并向服务端呈现出口 IP；它不构成官方授权或零账号风险保证。详见 [查询边界](../USAGE-QUERY-RISK.md)。

当前为 ad-hoc 签名、未经过 Apple 公证。升级后首次主动访问钥匙串仍可能需要系统授权，后台不会反复弹窗请求。

## English

Current subscription usage now refreshes quietly: about every five minutes while in use and every fifteen minutes while idle. Panel opening, wake and account changes catch up stale data without repeated manual checks. Local account metadata is observed every fifteen seconds without network requests.

Background reads never request authorization UI, renew credentials or switch logins. Manual refresh retains the official CLI path and may request permission. Failures preserve the last sample and timestamp; rate limits honor Retry-After. Weekly-only plans remain supported. Disk profile, actual mode, identity and token are rechecked before and after a request to reject stale results.

202 core tests, 237 isolated controller checks and the release build passed. Cloud CI was not run: GitHub rejected workflow dispatch with HTTP 422 (Actions disabled). Guard policy and network enforcement are unchanged. The build is ad-hoc signed and is not notarized.
