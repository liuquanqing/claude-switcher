# Claude Switcher 1.3.6 RC15

- 默认 Claude Code 登录核对成功后，保存最新登录的本地备份；打开已有匹配登录时也会补存。
- 后台观察会定期比较当前默认登录与备份，覆盖应用冷启动及官方 CLI 自行续期后的凭据轮换。相同内容不重复写入。
- 手动刷新在用量操作结束后补存最新凭据；权限或回读失败时明确提示备份未更新，后续可重试。
- 备份只复制账号和组织匹配的本地登录快照，不联网核对、不替换当前登录、不强制续期。独立目录不写入默认登录的备份。

**Apple Silicon · macOS 13+ · 预览版。** 较早预览版可在齿轮菜单开启「接收预览更新」后检查更新。

Default Claude Code logins are now backed up after successful confirmation and refreshed locally after credential rotation by the official CLI. Cold starts and manual refreshes also catch up pending backups. Backups do not modify the live login, trigger renewal, or require an online identity check.
