## 本版更新

联合切换桌面和默认 CLI，或手动同步 CLI 成功后，现在会通过既有网络门禁，向官方 CLI 请求一次当前账号的用量。

此前登录虽然已经切换，原生额度缓存仍可能属于上一个账号。软件正确拒绝了这份旧数据，却没有补查，因此卡片停留在历史额度、底部显示“用量未更新”。本版补齐这一步。

- 当前账号已有新鲜、匹配的缓存时，复用缓存，避免重复请求。
- 查询失败保留原采样时间，不伪造“刚刚更新”，也不把额度失败当成账号切换失败。
- 切换失败、仅切桌面的例外操作，以及平时打开面板，不触发这次额外请求。

- **复用已完成的核验**：联合切换及同步的身份核验、保存回读结果直接显示；不再为了更新 CLI 状态重复读取凭据。仅恢复过期保存登录时仍明确保留待刷新状态。
- **自动出口检查结果可见**：操作中的网络检查会更新设置里的检测详情，按实际使用的已保存配置显示结果；授权等待后，发送在线身份请求前、退出旧客户端前会再次检查出口；打开新客户端前仍保留复检。
- **统一刷新入口**：底部刷新状态；CLI 行不再单独放刷新按钮，点击状态可查看原有详情。平时打开面板仅观察本地状态，不弹出新的认证流程。

守卫的出口判断、拦截和持续检测规则不变，不增加跨账号轮询。Ultra 无五小时限制的显示兼容暂未纳入本版。

## 验证与安装

196 项 Core 测试、196 项隔离控制器检查；回归夹具专门模拟“登录已换、额度缓存仍属于旧账号”，验证显式刷新会调用一次模拟 CLI 并取得正确身份的数据。测试不使用真实账号、钥匙串或会话。

[额度读取说明](../USAGE-REFRESH.md) · [授权提示说明](../CLI授权提示说明.md) · [安装指南](../INSTALL.md)

当前仍为 ad-hoc 签名、未公证。升级本机应用后，钥匙串可能再次请求授权；本版没有解决签名身份跨版本继承问题。官方 CLI 或桌面端访问共享凭据，也可能触发系统 `security` 授权；本版减少重复检查，不承诺所有系统密码弹窗消失，也不改第三方凭据权限来强行启用指纹。已开启守卫时，不要随意移动或覆盖其程序路径，请按安装指南完成升级。原版和旧版本附件继续保留。
