# Claude Switcher 1.3.8 RC1

API 模式跳过订阅 Claude Code 登录备份，也隐藏此前的备份提示。后台备份失败时保持安静，成功后清除对应的提示。

在订阅模式下，手动刷新会核验匹配当前桌面账号的默认 Claude Code 登录，再更新备份。需要续期、系统授权或暂时无法在线核验时，界面会说明原因。

API mode skips subscription CLI backups and hides previous backup notices. Background backup failures stay quiet. Manual refresh verifies the current subscription CLI identity before saving an updated backup and explains why a backup is pending.

Apple Silicon · macOS 13+
