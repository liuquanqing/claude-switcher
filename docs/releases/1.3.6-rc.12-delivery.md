# RC12 交付记录

版本 `1.3.6-rc.12`，构建 `20261109.12.0`。本版为公开预览，1.3.5 保持正式 latest。

## 实现

- 网络诊断操作与结果合并，结果行控制详情展开；失败时保留具体出口与目标国家。
- 第三方 IP / WebRTC 体检位于结果详情，不与主动诊断并列。
- 暂停保护降低视觉强调，草稿保存入口不变。
- 现场只读核对：网络诊断未关闭后台守卫；`enabled=true`，守卫注册且回执持续更新。当前桌面记录为未纳入，这不等于后台守卫被诊断暂停。

## 验证

- 256 项 Swift Core 测试通过。
- 483 项控制器/Store 回归通过；新增保护中诊断不改变开关、桌面绑定、守卫判断和回执时间的检查。
- 虚构数据截图复核普通与 API 模式的诊断通过、国家不符、收起、草稿、暂停及中英文布局；没有用真实账号或网络故障作为测试夹具。
