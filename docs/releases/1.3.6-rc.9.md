# 1.3.6 RC9

在 RC8 基础上统一普通与 API 模式的界面层级，并补齐额度读取与保护状态的细节。

- 保留老版本的紧凑账号卡、额度数字和两行摘要。API 模式明确管理来源与订阅保护范围，不将已保存档案误标为当前桌面账号。
- 额度失败使用中性提示，原因留在详情；旧缓存保留原采样时间，不重复堆叠警告。重置窗口到期时明确显示。
- 兼容官方 CLI 的原生 `/usage` 输出，即使 `.claude.json` 缓存未变化，也可读取有效的对应账号结果。
- 主动额度查询复核账号关联、订阅保护、目标国家和代理出口；查询子进程仅允许访问选定本机代理。失败或身份不符时保留原数据。
- 区分后台守卫状态与手动网络诊断，移除重复的状态栏悬浮提示，并收敛展开设置与认证说明。

支持 Apple Silicon、macOS 13+。应用仍为 `Claude Switcher Preview.app`，原版可保留。
