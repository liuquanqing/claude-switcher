# Claude Switcher 1.3.7

在账号卡上点「切换」后，普通终端里的 `claude` 也会跟着换成这个账号。切换前，先把切出账号的最新登录存进它的备份和独立目录，再写入新账号。写回失败时停止切换，默认登录保持原样。

同一个账号同一时间只在一处使用：它是当前账号时，Switcher 顶部的终端图标和普通终端都用默认目录。默认终端和桌面账号不一致时，会出现「切到当前账号」按钮，点了才同步。已打开的终端只提示，不会被关闭。默认目录和各独立目录的历史分别保留。

Switching an account card now also switches the default Claude Code login used by ordinary terminals. The outgoing account's latest login is saved to its backup and own directory first; a failed write-back stops the switch and leaves the default login unchanged. A "Switch to current account" action appears when the default terminal and the desktop differ. Open terminals keep running.

Apple Silicon · macOS 13+
