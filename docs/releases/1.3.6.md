# Claude Switcher 1.3.6

当前账号旁可以直接打开或显示 Claude 桌面版。终端入口显示绑定的目录，保护状态可以展开查看。账号切换按钮保留在各账号卡上。

已有的默认和独立 CLI 登录继续使用各自的目录。升级保留原绑定。切换桌面账号不会自动迁移 CLI 凭据。

Open or show Claude Desktop from the active account header. The terminal shortcut uses the account’s bound directory. Expand the protection row for network details. Existing CLI sign-ins retain their directory bindings.
