## 本次更新

- **登录与额度一起收尾**：当前 CLI 登录恢复后，核验、备份与额度补查接续完成，避免登录已恢复却仍只看到旧额度。
- **少一些重复授权**：后台不请求系统弹窗；同一操作减少重复交互读取，取消后不追着请求。锁定后恢复可读的有效登录也能继续静默确认。真实系统权限仍由 macOS 决定。
- **检查与下载更新**：从设置中检查 GitHub 新版本、下载并验证安装包；正式与预览通道分开，安装仍由你确认。
- **工具栏更简洁**：检查更新、登录时启动和语言集中到设置；成功时间只显示“几分钟前”，完整采样时间在帮助里；退出动作统一为“退出”。
- **延续原有界面**：更新窗口采用现有暖灰按钮与语义色，账号卡和主要操作保持原有结构。

这是预览版，不替代 1.3.5 正式版。真实 OAuth 恢复、不同机器的钥匙串授权继承不以假数据验收替代；首次访问不同凭据项目仍可能要求系统授权。RC1 与本版的 GUI 签名身份要求相同，不代表所有项目已自动获权。

本版没有新增网络层即时断流，也不会全局接管现有 CLI 任务。已启用独立守卫的用户，升级或清理旧包前须保留注册路径所需组件，勿直接删除承载守卫的目录。

## English

Current-login recovery, identity verification, backup and quota catch-up now share one flow. Background reads do not request authorization UI; manual operations avoid repeated interactive reads. Settings groups updates, launch at login and language. Verified update downloads are available from GitHub; installation remains user-confirmed.

The app and DMG are Developer ID signed, notarized and stapled. 228 core tests, 319 isolated checks and exact-source CI passed. This is a prerelease. Real authentication and Keychain permission inheritance remain environment-dependent; no live login or conversation was used as a test fixture. Existing CLI tasks are not globally managed, and this release does not add packet-level network blocking.
