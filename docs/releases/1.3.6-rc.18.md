# Claude Switcher 1.3.6 RC18

V5 面板把「打开 Claude」放在当前账号旁边。终端入口显示默认或独立目录，保护行显示最近核验的出口。授权等待时可以返回终端或核对登录。

本版沿用 RC17 的 CLI 目录绑定和登录存储。已绑定的独立终端继续使用原目录。切换桌面账号时保留默认终端登录。

The V5 panel brings the desktop launch action and terminal shortcut into the account header. Existing CLI directory bindings and sign-ins continue to use the RC17 storage behavior.

Apple Silicon · macOS 13+
