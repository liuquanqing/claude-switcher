# Claude Switcher 1.3.6 RC16

- 修复默认 CLI 凭据已空、但仍留有账号记录时跳过旧备份恢复的问题。
- 手动恢复过期备份时，使用官方 CLI 在独立恢复目录续期。核验账号、组织和有效期后，再写回默认 CLI。
- 官方 CLI 未能写出可用的新凭据时，保留恢复资料并提示失败。恢复仍由用户主动发起。

**Apple Silicon · macOS 13+ · 预览版**

Fixes manual backup recovery when the default CLI keeps account metadata after losing its credentials. Expired backups must be renewed in an isolated directory using the official CLI before the restored login is applied.
