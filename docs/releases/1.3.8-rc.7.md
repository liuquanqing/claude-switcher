# Claude Switcher 1.3.8 RC7

修复默认终端登录同步报「桌面登录缓存格式不兼容」的问题：当 Claude 桌面版在 `oauth:tokenCacheV2` 中写入 `null`（如已失效的 `user:sessions:claude_code` 项）或混合元信息字段时，不再整体拒绝解析，正常提取有效的 `user:profile` 令牌用于身份核验与默认终端同步。

升级「同步会话」功能：严格按链切换时刻区分线性接续与分叉（不再按跨身份轮数判断谁新）；预演清单明分为新增、覆盖、分叉、跳过并附原因，分叉默认以末轮有效消息较晚一支为主、另一支另存为「｜旧分支」且支持逐条切换；新增截止日期默认按目标最早活跃会话自动推算；目标为运行中的活跃档时支持锁定切档、等待退出与 8 秒落盘后自动安全写入、写后自动核对、15 秒安全重开提示及一键原子撤销。

Fixes "desktop token cache format incompatible" errors during default CLI sync when Claude Desktop writes `null` or mixed metadata entries in `oauth:tokenCacheV2`. Upgrades Session Sync with chain-based fork detection (never comparing per-identity turn counts), per-item fork resolution with parked branch clones, auto-inferred new-session cutoffs, built-in wait-for-quit with profile-switch lock, post-write verification, and atomic one-click undo.

Apple Silicon · macOS 13+
