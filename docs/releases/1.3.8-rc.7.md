# Claude Switcher 1.3.8 RC7

修复默认终端登录同步与桌面凭据解析问题：
- 当 Claude 桌面版在 `oauth:tokenCacheV2` 中写入 `null`（如已失效的 `user:sessions:claude_code` 项）或混合元信息字段时，不再误报「桌面登录缓存格式不兼容」，正常提取有效的 `user:profile` 令牌用于身份核验与默认终端同步。
- 切回已超过 8 小时未使用的账号时，在切换默认终端登录前通过官方 CLI 自动续期已保存的 CLI 备份，避免切档后默认终端滞留在旧账号或反复要求手动 `/login`。
- 默认终端已跟随当前账号时，顶部终端入口标签同步显示「默认」而非滞留「独立」。

升级「同步会话」功能：
- 严格按链切换时刻区分线性接续与分叉（不再按跨身份轮数判断谁新）；目标中无 `cliSessionId` 的草稿条目自动跳过，不再阻塞整批同步；来源/目标存在唯一匹配的 Code 空间时自动选中。
- 预演清单明分为新增、覆盖、分叉、跳过并附原因，分叉默认以末轮有效消息较晚一支为主、另一支另存为「｜旧分支」且支持逐条切换；新增截止日期默认按目标最早活跃会话自动推算。
- 目标为运行中的活跃档时支持锁定切档、等待退出与 8 秒落盘后自动重算并安全写入、写后自动核对、15 秒安全重开提示及一键原子撤销。

Fixes "desktop token cache format incompatible" errors when `oauth:tokenCacheV2` contains `null` or mixed metadata entries, auto-renews expired (>8h) saved CLI backups via the official CLI before swapping the default terminal login, and keeps the header terminal label in sync. Upgrades Session Sync with chain-based fork detection (never comparing per-identity turn counts), automatic matched Code space selection, non-CLI draft tolerance, per-item fork resolution with parked branch clones, auto-inferred new-session cutoffs, built-in wait-for-quit with profile-switch lock and post-quit replan, post-write verification, and atomic one-click undo.

Apple Silicon · macOS 13+
