# Claude Switcher 1.3.0

让账号、终端与手上的会话，在菜单栏里接续起来。

**[下载 macOS DMG](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.0/ClaudeSwitcher-1.3.0-arm64.dmg)** · [SHA256 校验](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.0/SHA256SUMS)

Apple Silicon · macOS 13+

## 本版带来什么

- **账号切换与用量**：独立保存桌面账号目录，在切换前检查网络与默认 CLI 登录条件。
- **桌面与 CLI 衔接**：切换时备份并同步默认保存的订阅登录；已运行的终端任务保留现状，不强制结束。
- **会话导入与恢复**：保留会话列表与搜索，支持适配索引的新增、显式增量、备份和撤销；有冲突时停止写入。
- **后台守卫**：持续观察明确纳入的订阅桌面，关闭面板后可继续运行。

## 相比 RC6

- 首页显示 Magpie、CC Switch 或尚未确认的 API 配置来源，提供已识别工具的打开入口。
- CLI 默认登录的保存身份与主动检查结果分开呈现；本地报告不冒充在线凭据有效或运行中任务的身份。
- 后台凭据读取不请求系统授权；需要授权时保留未确认状态，不误报为退出登录。主动检查仍可能触发官方 CLI 自身的系统授权。
- 调整终端与保护区域的文案、对齐和操作入口，减少重复提示。
- 修正控制器测试对固定等待时间的依赖，改为等待查询阶段及完成结果。
- 安装包内应用统一命名为 **Claude Switcher.app**，不再显示“候选版”。

## 安装与升级

打开 DMG，将 **Claude Switcher.app** 拖入“应用程序”。若需要保留同名原版，请先给原版改名或备份；本版与原版共享账号目录，请只用一个管理器切号。

从 RC6 升级且已开启守卫时，请先在旧版关闭保护，退出切换器与 Claude Desktop，再安装并按新路径启用保护，避免守卫引用已移动的旧 helper。安装包不会自动迁移或删除账号、登录及会话数据。

当前采用 **ad-hoc 签名，未经过 Apple 公证**。首次打开被 macOS 阻止时，确认来源与校验值后，在“系统设置 → 隐私与安全性”中仅为本应用选择“仍要打开”。详见[安装说明](../INSTALL.md)。

## 验证与范围

发布验证覆盖 176 项 Core 测试、121 项控制器隔离检查，以及 release 构建与签名验证。测试使用虚构数据、模拟服务和临时目录，未读取真实登录、钥匙串或会话作为测试数据。

后台守卫约每 10 秒检测一次；网络层隔离与即时阻断尚未接入本版。CLI 同步管理默认保存的登录，不代表所有运行中终端任务都已换号。会话导入面向适配的本地桌面索引，不等同于完整云端聊天迁移。

完整边界见[验证说明](../VALIDATION.md)与[API / CLI 状态说明](../API-CLI-STATUS.md)。安装包的准确源码提交及校验值见附件 `RELEASE-MANIFEST.json` 与 `SHA256SUMS`。
