# 1.3.6 RC11 · 预览版

本版让桌面账号和终端登录各自回到清晰的使用路径，同时收敛账号状态与保护设置。

- 当前桌面订阅账号可独立刷新额度，不要求 CLI 登录。查询前复核桌面身份与代理出口；无权限、限流、失败或身份不符时保留旧采样和原时间。
- 打开终端先复用已核验目录；有旧 CLI 备份时提供明确恢复入口，没有可用登录再走官方登录。不会为桌面切换自动覆盖默认 CLI 登录。
- 终端摘要区分本地记录、已核验一致和账号不同；不一致显示实际默认 CLI 身份或待确认，不冒充桌面账号。
- 会话导入窗口在前台打开，优先显示可匹配邮箱、档案名或会话标题；没有匹配身份时不猜测。复制、备份、撤销与恢复继续保留。
- 底部可直接刷新订阅额度和检查更新，全局中英文、登录时启动与预览版偏好保留在设置里。
- 保护面板更紧凑：暂停按钮弱化，国家使用短输入框，代理与保存状态保持一行，只有修改后才显示保存操作。诊断首屏只保留结论，手动诊断的只读边界仍在帮助中。

支持 Apple Silicon、macOS 13+，应用名为 `Claude Switcher Preview.app`，原版可保留。RC7 及之后版本支持一键更新；更早版本先安装一次完整新包。升级不会替你切号、恢复凭据或迁移真实会话。

完整测试、签名、公证、分发与本机安装结果见 [RC11 交付记录](1.3.6-rc.11-delivery.md)。
