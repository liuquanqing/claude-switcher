# Claude Switcher 1.3.6 RC14

- Claude 域名探测超时或出口未确认时，后台守卫保留已打开的桌面并继续检查；新启动和账号切换仍需全部通过。
- 仅一路超时、其余两路均确认目标地区且代理和 TUN 仍在线时，守卫以 3 秒超时复测原域名一次。
- 明确测到非目标出口、不同域名出口不一致，或确认代理/TUN 断开时，仍关闭已纳入保护的桌面。守卫不重启 Claude。
- macOS 系统日志区分账号切换请求退出和网络守卫关停，不写账号、会话或凭据。

**Apple Silicon · macOS 13+ · 预览版。** 已安装较早预览版的用户可在齿轮菜单启用「接收预览更新」，再选择「检查更新」。

The guard now keeps an open desktop running when a route check is inconclusive. It still closes protected desktops when it confirms a wrong exit country or a proxy/TUN disconnect. New launches and account switches continue to require a complete passing check.
