# Claude Switcher 1.3.6 RC17

## 终端登录

- 首次打开终端时先选择默认目录或独立目录。已有绑定沿用原目录，并核对账号与组织。
- 浏览器无法回跳时，可以返回 Terminal，使用官方 CLI 打印的备用登录链接，并将网页授权码粘回原终端。
- 旧额度错误需要同一目录的最新官方登录状态确认。默认登录比较原生凭据版本，晚到的旧查询结果不会覆盖新报告。
- 恢复旧备份仍须单独确认。

## 终端与代理

- 终端账号不同或需要准备登录时，选择页会核对备份的账号、组织和本地凭据。可尝试恢复时，优先显示「用备份切到〈账号〉」，仍需用户确认。
- 错绑或没有可用凭据的备份会显示原因，请使用官方登录。等待登录时，也可从终端详情重新打开「登录选项」。
- 默认终端与独立目录继续分别管理登录。恢复仅在用户确认后执行。
- 终端门禁直接核验 CLI 将使用的本机代理出口。守卫回执、TUN 和目标域名仍须通过检查。

**Apple Silicon · macOS 13+ · 预览版**

The terminal picker now checks local backup ownership and credential availability before offering a switch. Waiting for sign-in also offers a way back to the terminal options.

Unbound accounts now choose a directory before sign-in. Terminal details guide users through the official paste-code fallback. Stale auth results cannot override a newer verified report.
