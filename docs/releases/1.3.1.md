# Claude Switcher 1.3.1

全局中英文，清晰的会话复制。

**[下载 macOS DMG](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.1/ClaudeSwitcher-1.3.1-arm64.dmg)** · [SHA256 校验](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.1/SHA256SUMS)

Apple Silicon · macOS 13+

## 本版更新

- **全局中文 / English**：通过底部地球图标切换首页、CLI 状态、保护设置、复制与恢复、确认框和菜单；已打开的复制窗口也会同步更新。
- **保留工作状态**：语言切换保留搜索和未保存设置，兼容旧版语言偏好。账号名称、会话标题、路径与原始诊断保留原文。
- **英文排版**：适配现有 500pt 主面板和 680pt 复制窗口，精简较长的状态文字，完整说明保留在帮助中。
- **复制会话**：统一“复制会话 / Copy sessions”与“开始 / Start”；完成摘要显示实际目标及新增、更新数量，索引共享范围在备份预览中按需查看。
- **语言扩展准备**：菜单、支持校验与日期区域使用统一语言注册表。目前提供中文和 English；后续语言需补齐翻译、模板和排版验证后再启用。

界面与文案由 Kimi CLI 完成，Codex 负责后端衔接、审查、隔离测试和发布。

## 验证

176 项 Core 测试、147 项控制器隔离检查，以及 release 构建和签名验证通过。中英文应用文案各 266 个键、复制文案各 79 个键，键及插值参数配对检查通过。

原生演示覆盖双向切换、已有窗口同步、搜索保留、全选与半选、确认与取消、新增加更新、备份预览、撤销和返回。复制与恢复仅使用临时虚构会话，没有用真实登录或会话做验收。

## 安装与升级

打开 DMG，将 **Claude Switcher.app** 拖入“应用程序”。需要保留同名原版时，请先改名或备份。两版共享账号目录，请只使用一个管理器切号。

已开启守卫的用户，整包覆盖或更换应用路径前，请按[安装指南](../INSTALL.md)退出 Claude 桌面并完成守卫交接，避免旧 helper 路径失效。

当前仍使用 **ad-hoc 签名，未经过 Apple 公证**。首次打开被 macOS 阻止时，确认来源和校验值后，在“系统设置 → 隐私与安全性”中仅为本应用选择“仍要打开”。

## 范围与来源

守卫仍约每 10 秒观察一次已明确纳入的订阅桌面；CLI 同步管理默认保存的登录，不会强制结束正在运行的任务。网络层隔离与即时阻断尚未接入本版。会话复制面向已适配的本地索引，不等同于完整云端聊天迁移。
