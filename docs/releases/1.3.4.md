## 本版更新

修复首次安装时，Claude 桌面已运行、CLI 已登录并有用量缓存，账号卡片却仍显示“暂无账号信息 / 暂无用量数据”的问题。

此前刷新只能把用量匹配到已经保存过身份的档案，新电脑还没有这份资料，因而一直无法完成第一次匹配。本版先确认当前桌面自己的身份，再关联官方 CLI 用量。不会拿 CLI 邮箱代替桌面身份，也不会自动初始化其他账号。

- **首次打开自动补齐资料**：从切换器成功打开桌面后，缺少身份资料时完成初始化；日常显示已有桌面不重复触发这一步。
- **身份与额度分开呈现**：只有账号信息、还没有真实额度窗口时，继续显示无用量占位。不会伪造“刚刚更新”或继承其他账号的旧额度。
- **CLI 状态保持连贯**：首次关联到桌面档案时保留已经取得的登录报告；若新资料揭示两端不同，仍如实显示不一致。
- **空白档案更准确**：初始化创建的空目录不再显示为已发现的登录账号。

自动刷新不会弹出授权界面。首次读取桌面保存登录时，如果尚无系统许可，主动点击底部刷新后可能需要授权；这与退出账号、重新登录不同。

## 边界与验证

196 项核心测试、213 项 controller/store 隔离检查通过，发布构建及签名检查完成。回归使用空缓存、虚构身份、模拟 CLI 与临时目录，覆盖首次读取、身份不一致、授权失败、期间换号和真实采样时间保留；没有使用真实账号或会话作为测试数据。

本版不改变守卫规则，不提供新的网络层阻断能力，不自动接管“桌面未纳入”的进程。相关隔离研究仍未接入产品。

当前为 ad-hoc 签名、未经过 Apple 公证；升级后系统仍可能重新询问钥匙串授权。本版没有更改凭据权限，也没有解决所有跨版本授权提示。

## English

Fixes empty account and usage cards on a fresh installation. The app now establishes the active desktop's own identity before matching official CLI usage. Opening an uninitialized desktop triggers the first read; showing an already-known desktop does not repeat it. Identity-only records keep the no-usage placeholder, empty account slots no longer look signed in, and CLI login reports survive the initial profile mapping without hiding a genuine mismatch.

Background reads do not request authorization UI. A first explicit refresh may require permission to read the saved desktop login. Guard policy, live sessions and network enforcement are unchanged. The build remains ad-hoc signed and is not notarized.
