# 1.3.6 RC7

把 CLI 关联、保护重试和软件升级整理成直接的操作。此版本继续使用 Preview 渠道，1.3.5 正式版保留。

## 更新内容

- **打开 CLI**：现有默认登录与桌面账号、组织匹配时直接沿用；否则通过官方 CLI 为该账号独立登录。以后复用原目录，保持原登录和历史。
- **保护重试**：开启后等待有效回报；失败时原位重试，无需先暂停再开启。守卫在线与网络放行仍分别判断。
- **更新并重启**：校验安装包、签名和版本后替换完整应用；新版启动未确认时回退。应用拒绝退出则保留原包，不强制结束。
- **更清楚的状态**：超时或权限不足显示检查未完成，不误报退出登录；中英文提示与首次关联面板经过虚构数据复核。

## 安装

[下载 Apple Silicon DMG](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.6-rc.7/ClaudeSwitcher-1.3.6-rc.7-arm64-developer-id-preview.dmg) · [SHA256](https://github.com/liuquanqing/claude-switcher/releases/download/v1.3.6-rc.7/SHA256SUMS)

支持 macOS 13+，Apple Silicon。应用为 `Claude Switcher Preview.app`，保留原版应用即可。

RC6 及更早的 Preview 需要先安装一次完整的新包，后续可使用「检查更新」完成安装和重启。启用守卫时，完整应用应继续放在原安装位置；不要只替换单个可执行文件或随意移动它使用的组件。

## 使用边界

普通终端里的 `claude` 继续使用原默认目录；「打开 CLI」选择当前桌面账号的关联目录。已运行的 CLI 任务不会随桌面换号。独立目录有自己的历史列表；旧记录保留原处，需要时再通过会话导入带过去。

独立目录不会自动获得桌面登录授权，首次仍需官方登录。没有恢复或续期任何用户的失效备份，也没有执行真实网络故障、急停或真实会话迁移验收。

开发者签名与 Apple 公证不代替系统授权，也不能保证钥匙串今后永不询问。验证结果见 [签名更新验收](../signing/RC7.md)。
