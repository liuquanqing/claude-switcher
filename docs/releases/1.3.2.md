## 本版更新

- **可关闭的操作提示**：黄色“上次操作”提示新增 ×；关闭只隐藏历史提示，不改变保护、账号或待确认的切换操作。
- **CLI 旧备份恢复**：过期且缺少新版核验记录的备份，可在独立配置目录中交给官方 CLI 尝试恢复。身份核验、保存和回读通过后，再继续联合切换；正常使用不需要手填 token。
- **保留当前登录**：缺少目标 CLI 登录时不再清空当前默认登录；失败保留恢复资料，后续重试优先读取已经续期的结果。原有可信备份保留原恢复路径。
- **真实的额度时间**：后台读取官方 CLI 缓存，手动刷新通过门禁后调用官方 `/usage`。只更新身份唯一匹配的账号，其他卡片保留历史数据；额度提示不再覆盖切换错误。
- **更清楚的显示**：重置时间和缓存年龄按分钟更新，到期但尚无新数据时显示待刷新。语言按钮使用与其他底部按钮一致的渲染方式。

界面与中英文提示由 Kimi CLI 完成；Codex 负责后端、审查、隔离验证和发布。恢复代码经过 Claude CLI 只读审查，相关问题已由隔离测试覆盖。

## 验证与边界

195 项 Core 测试、186 项控制器隔离检查通过；本地 release 构建与签名验证通过。测试使用虚构凭据、模拟 CLI、临时目录；本机官方 CLI 2.1.314 的独立目录读取及离线 `/usage` 缓存路径也已核对。

**真实账号在线续期未作为本轮验收。** 服务端已撤销的刷新凭据仍需用户重新登录，不能保证任意旧备份都可恢复。默认 CLI 登录的同步不代表所有已运行终端、项目或 API 配置都会同步；软件不会强制结束 CLI 任务。

## 安装与授权

打开 DMG，将 **Claude Switcher.app** 拖入“应用程序”。已有同名原版请先改名或备份；多个管理器共享账号目录时，请避免同时切号。

已开启守卫的用户，整包覆盖或更换应用路径前请按[安装指南](../INSTALL.md)完成交接。本机受控升级可仅替换界面程序并保留正在运行的 helper；普通拖拽安装不等同于这种交接。

当前仍为 **ad-hoc 签名，未经过 Apple 公证**。首次打开可能需要在系统设置中为本应用授权；更新后的签名指纹变化，也可能导致钥匙串重新询问。**本版减少了不必要的读取，但没有彻底解决升级后的重复授权。** 不建议放开所有应用的钥匙串访问权限。
