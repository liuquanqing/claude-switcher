## 本次更新

- **底栏更清楚**：相对采样时间保持可见，复制会话、刷新、设置与退出排列在右侧。低频的账号目录入口收进设置，常用操作仍可直接点击。
- **设置融入工具栏**：图标默认颜色与相邻工具一致，修正原生菜单额外占宽造成的布局问题。
- **缓存各有归属**：账号卡精简为“缓存 · 8 小时前”。旧数据不再只写“更新”；失败、未请求、加载中、重置待确认继续明确区分。
- **保留熟悉的结构**：卡片位置和高度、全局时间含义、切换和保护策略不变。

## English

RC3 restores a visible sample age, keeps session copy, refresh, settings and quit on the right, and moves the account directory command into Settings. Per-account cache labels are shorter and distinguish cached data, failed reads and requests that were not made. The settings icon now uses the same neutral color as adjacent tools.

228 core tests, 319 isolated checks and 22 fictional layout states passed their respective checks. Keyboard navigation and VoiceOver have not been revalidated. The app and DMG are Developer ID signed, notarized and stapled; final hashes and package verification passed. This remains a prerelease; installed guard paths and real accounts must be preserved during an upgrade.
