# 1.3.6 RC8

以桌面账号为主，终端和保护状态保持简洁。界面、交互与产品文案由本机 Kimi 修改，后端与整合验证由 Codex 完成。

- 首页只显示终端账号摘要；准备、打开及核对移入详情。读取本地记录不会启动 CLI 或请求授权，也不把缓存记录当成登录有效性的证明。
- 切到 A 时读取 A 对应的终端记录，切回后复用原目录；不覆盖默认登录，不改变已经运行的终端任务。普通 `claude` 命令仍使用原默认配置。
- 当前账号的专用终端缓存也能被自动读取，避免账号已对应而额度仍只从默认目录读取。采样时间保留官方原值，其他账号的缓存不会冒充当前账号。
- 桌面 API 模式沿用顶栏的原工具入口，下方仅显示订阅保护不参与此模式；不再展示没有目标的终端按钮，不推断 CLI 也被该工具接管。
- 已识别来源只显示一次工具名，删除重复的来源说明，管理入口使用中性次级样式；来源未知或冲突时仍保留必要提示。
- 暂停保护放入展开设置；API 模式仍可管理订阅守卫，设置说明其不影响 API 配置。状态失效、权限不足或读不到记录不等于退出登录。

支持 Apple Silicon、macOS 13+。应用仍为 `Claude Switcher Preview.app`，原版可保留。
