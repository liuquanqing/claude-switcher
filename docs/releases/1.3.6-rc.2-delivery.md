## 本机更新与清理

最新 GUI 已在 `/Applications/Claude Switcher Preview.app` 升至 RC2 并启动。最初原版 `/Applications/Claude Switcher.app`（1.2）完整保留；旧 GUI 包和旧别名已移入废纸篓，不做永久清空。应用目录内具有有效 Info.plist、可启动的本项目应用仅剩这两份。

旧注册守卫的路径仍是 `/Applications/Claude Switcher 候选版.app/Contents/Helpers/ClaudeGuard`。为避免卸载／重启服务，旧路径已原子替换为隐藏的**兼容运行目录**，只有原守卫组件和说明，没有 Info.plist 或旧 GUI。原守卫文件的字节、inode、mtime、配置、进程记录与 LaunchAgent 未改，服务保持注册，更新后回执继续推进（采样时距最近回执 0.7 秒）。这不是另一份可启动旧软件；在服务仍引用它期间不要手动删除。完全去掉兼容路径需要另行计划守卫交接，不由本次清理顺带执行。

清理前已用临时虚构目录测试原子交换、同 inode 连续可读和回滚。真实安装器只正常退出已核实的旧切换器 GUI，不强杀、不触发真实认证／迁移，不操作 Claude Desktop、既有 CLI 任务、代理或网络。独立守卫不停止。

本机正常启动后的只读观察与缓存更新属于软件常规行为，不代表真实 OAuth 续期或钥匙串授权持续生效已经验收。MBP16 本次未操作。
