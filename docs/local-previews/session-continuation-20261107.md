# 会话复制：分类收窄与续接更新

日期：2026-11-07。本机源码修订，尚未构建、安装或发布。

## 分类调整

- 两端都没有轮数字段、活动时间相同：判为“已同步”。
- 来源已归档或删除：一律跳过，显示“两边均已归档”或“来源已归档”，不再显示为暂不处理。仅目标归档的仍保留目标状态。

## 续接更新

目标停在来源的旧聊天分段、且能证明目标在分段切换后没有继续时，显示为“续接更新”。默认不勾选；手动勾选后，确认框把续接项排在最前，说明目标将指向新分段。写入只替换续接链字段，目标标题、模型、权限、连接器和未知字段保留，并沿用自动备份与撤销。缺少切换时间、目标或旧分段在切换后仍有变化、续接链不一致时，继续显示暂不处理，并写明“可能已分叉”等具体原因。规则详见[会话迁移方案](../会话迁移方案.md#续接更新)。

## 验证

- 256 项核心测试、428 项控制器检查通过；新增用例覆盖续接写入与撤销、五类证据不足或分叉、计划后旧分段被追加、反方向分叉，以及默认不勾选和确认框排序。
- 变异检查：去掉旧分段修改时间判断后，相关测试失败。
