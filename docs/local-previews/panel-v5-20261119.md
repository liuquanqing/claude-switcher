## 结构

- 顶部账号卡：图标、账号名（单行省略，悬停显示全名）、套餐标签、邮箱 · CLI 目录；右上角终端图标（悬停出底色，需处理时右上角小点）和主按钮。
- 主按钮三态：未运行「▶ 打开 Claude」；运行中「● 运行中 | 显示」；上次启动被出口门禁拦下时锁定为「出口未确认」，悬停给出原因。API / 未知模式保留「管理」入口。
- 保护行：桌面与终端共用，正常只显示「保护中 · SG · 时间」；未接管 / 暂停 / 拦截各有原因和对应按钮；展开区三格来自真实检查报告，检查中显示「检查中」，未接管时出口格显示「此桌面未验证」。
- 终端只在需要处理时出一行：等待授权（「已完成授权」→ 核对中… → 成功才收起）、账号不符、预检失败；「稍后」收起直到状态变化。未设置 / 目录占用由终端图标弹出选择框，两个选项各显示完整路径；恢复旧备份保留独立破坏性确认。
- 账号卡：当前卡暖色高亮 + 细橙边；额度标签缩短为「5 小时 / 本周」。
