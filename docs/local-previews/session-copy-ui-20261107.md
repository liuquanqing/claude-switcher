# 复制会话窗口：分组、文案与配色

日期：2026-11-07。本机源码修订，尚未构建、安装或发布。

## 改动

- 列表分为“可复制 / 未复制 / 无需处理”三组，无需处理默认折叠；未复制行以琥珀色感叹号代替复选框，原因直接写在行内。
- 日期范围外的新会话在可复制组末尾提示条数，可一键显示全部；结果页同样按日期范围显示，不再列出未纳入的旧会话。
- 文案改为用户语言：“暂不处理”改为“未复制”，“开始”改为“复制 N 项”，“复制指令”改为“导出指令”，续接与分叉等原因改为短句；结果页续接项显示“已续接”。英文状态列不再截断。
- 配色撤下 RC6 的蓝色体系，回到全局暖灰规范。RC10 公开版曾用象牙色实底主按钮；之后改为与主面板“检查并打开”一致的 Claude 橙浅底胶囊（10–26% 底、26–30% 描边、橙色字），复选框勾选为橙底深色勾，列表容器为 `card` 圆角 12 且不描边，选中行为 `cardHi`。

## 验证

256 项核心测试、430 项控制器检查通过。中英文列表、确认框、结果页、搜索展开均用临时虚构数据离屏截图复核（`_qa/session-ui-audit/`，改前截图在 `before/`）。原生悬停、按下、键盘焦点与 VoiceOver 未实测。
