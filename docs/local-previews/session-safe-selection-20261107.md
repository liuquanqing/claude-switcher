# 会话新增与续聊更新：默认选择复核

日期：2026-11-07。此为本机源码修订，尚未发布或安装。

## 日常操作

选择来源与目标后，默认选中可安全新增和可安全更新的会话，不再先打开“更新已有会话”开关。底部直接显示“已选 N 项 · 新增 N · 更新 N”。手动取消后，普通刷新不重新选择；更换来源或目标会清空旧范围的选择。

包含更新时，仍先列出具体会话、要求确认并自动备份。只新增则直接执行。目标较新、已同步和续接/身份无法确认的记录不自动修改。后者以“暂不处理”代替“需核对”，原因保留在行内。

## 不变的保护

只更新同一逻辑会话、同一 CLI 段的可比列表进度，保留目标标题、路径及未知字段；不复制或改写 JSONL 原文，不修改 `sideSession`。不同 CLI 段缺少接续证据时不强行覆盖。
