# 新登录后本地备份补齐

RC14 的登录确认只更新状态，手动刷新也没有调用保存备份；旧备份的写入时间不能说明它对应最新登录。

新增纯本地快照入口：默认 CLI 登录核对成功后保存备份；手动刷新在用量查询结束后补存；后台已有账号观察每分钟最多尝试一次静默补存。备份比较的是完整 OAuth 字段和账号记录，完全一致时不重复写入。官方 CLI 自行续期后，下一轮可以保存轮换后的内容。

备份过程不联网核对、不执行续期、不写默认登录。缺少读取或写入权限时保留待备份状态，手动刷新可重试。账号/组织不一致、读取期间登录变化、备份回读失败均报未完成，不能显示已备份。纯本地快照不带远端核验凭据，不能冒充已联网核验。

本机 Personal 的旧备份已保留为独立钥匙串条目。以当前默认登录更新主要备份后，访问凭据、刷新凭据和账号记录回读完全一致；当前登录在写入前后保持一致，无网络请求。

RC15 候选增加虚构数据回归：冷启动本地记录可补存，官方 CLI 写入新凭据后下一次符合条件的后台检查更新备份；静默权限失败保留待备份状态，重试成功清除警告。官方续期成功后的备份与启动续期是不同动作，不承诺刷新令牌永远有效。
