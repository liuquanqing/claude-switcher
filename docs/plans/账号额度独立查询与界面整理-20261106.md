# 账号额度独立查询与界面整理

状态：本地候选开发与隔离验证；未安装、未公开发布，未使用真实登录或会话验收。

## 交互

保留桌面身份、左侧 CLI 与右侧保护、账号卡片的原有层次。API 桌面不能决定默认 CLI 的认证状态。CLI 行仅显示本机保存的默认配置观察，不宣称已识别全部运行终端。订阅桌面沿用现有明确的账号关联。

卡片隐藏“缓存”术语，旧数据仍显示每账号自己的更新时间；失败保留旧值与原采样时间。底部时间不代表每张卡同时刷新。

用户点刷新，先读取已有记录，再顺序查询已有可确认 CLI 关联的账号。无需先切换桌面，未关联账号不自动创建目录、不导入旧凭据。默认 CLI 元数据完整匹配的账号可以沿用该目录。自动观察仍每 15 秒只读本地数据，不启动 CLI、不申请钥匙串权限。

## 查询边界

- 仅调用官方 CLI `/usage`，不直接请求 OAuth API、不自行续期、不复制 token。官方 CLI 本身可能续期并写回它自己的存储，也可能触发系统授权；“没有手工覆盖凭据”不等于完全无写入。仅显式点击才允许此路径。
- 沿用已保存保护目标的门禁；保护未就绪、出口未知或不符合目标，拒绝查询。
- 从系统代理配置识别启用的本机 HTTP/HTTPS 代理，仅接受 localhost/127.0.0.1 和有效端口。不猜端口，不配置代理；纯 TUN、只有 SOCKS/PAC 或远程代理均暂不主动查询，显示具体原因并保留旧值。
- 使用 macOS sandbox-exec 限制新查询子进程只能连接指定回环端口，清空 NO_PROXY，设置同一代理环境。三个 Claude 域名的 HTTPS trace 都经该端口核验国家后才运行 CLI。禁止 curl 重定向、直接重试。系统路由、现有终端、其他软件不受影响。
- 官方 CLI 进程最多 45 秒；超时只结束本次新建子进程。返回后按 UUID 与组织再次检查归属，只采用新采样，查询失败不改变旧额度的时间。没有五小时窗口的计划保持缺省。
- 本次沿用现有 UsageRefreshPolicy：同账号至少 60 秒，普通失败退避 5 分钟；已有 30 秒内官方样本可直接使用。

## 已验证与未验证

虚构账号与注入 CLI 测试覆盖 B 独立查询、默认 A 和历史保持、路由错误/未知/超时不启动查询、身份变化与旧样本拒收、无五小时窗口。回环网络实验实际运行 macOS 沙盒与 curl，验证指定端口可达、另一端口被拒、无沙盒进程不受影响、代理端口关闭后失败。

没有用真实官方 CLI 登录做联网验收；不能把上述测试写成实际订阅账号兼容性通过。sandbox-exec 属于需维护的 macOS 兼容边界，不支持时拒绝查询，不降级直连。

该隔离限制查询子进程的目的地址，不能验证代理应用上游是否存在 DIRECT 分流，也不能锁定代理节点在请求途中不换国家。本轮不声称零泄漏或替代整机网络层防护；上线前仍需检查指定代理的 Claude 路由与官方 CLI 兼容性。
