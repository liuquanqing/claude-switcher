## 验证原则

测试只使用临时目录、假网络结果与假进程动作。真实账号、钥匙串、代理配置与已安装应用不作为测试夹具。网络检查、账号移动和会话复制的核心逻辑与 SwiftUI 分开，便于直接验证失败边界。

```sh
swift test
./build.sh
```

构建只生成仓库内的 App。安装、注册守卫和真实账号切换是独立步骤，不得把编译或演示成功写成真机验收通过。
