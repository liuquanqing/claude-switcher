# 复制窗口与历史空间识别

2026-11-08。本轮前端由本机 Kimi CLI 在隔离副本修改；后端只补充显示资料匹配和窗口打开时序。

- 打开复制窗口前收起菜单栏面板，再在下一轮主线程激活并置前复制窗口；切回主面板和操作中不可退出的规则保持。
- 邮箱来自已有档案身份或默认 CLI 账号资料，只在账号 ID 对应时使用。多个来源的邮箱冲突则留空；不按显示名称或短编号猜邮箱。组织名仍要求账号及组织同时匹配。
- 空间选择仍是显式选择，不自动猜目标，也不改变复制计划、备份、回滚或实际会话数据。
- 清理与修改 UI 分开：本轮先列出应用历史回退包和测试产物。原版、当前 Preview、最近回退包、真实账号目录、会话及登录资料列为保留项。测试目录可能包含当前交付源码和验证证据，不能整目录删除。

当前能读到的身份资料不等于历史账号的完整名单。缺少匹配资料的旧空间仍需通过会话线索辨认。
