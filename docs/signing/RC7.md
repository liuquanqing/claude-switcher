# RC7 签名与更新验收

版本 `1.3.6-rc.7`，构建 `20261105.7.2`。四个组件分别签名：主程序、守卫、会话助手和新增更新助手；外层 App 与 DMG 使用 Developer ID 签名、Apple 公证和票据验证。

## 隔离验收方法

`scripts/verify-signed-update.py` 用真实签名、公证的虚构应用调用产品的 `ClaudeUpdater`。测试目录全部位于 `_qa/signed-update/`：

- 每个案例使用独立用户目录与 `Applications` 目录。生产助手的缓存根及安装根校验仍保持原样，没有测试后门。
- 测试守卫配置显式关闭，生产代码从该虚构配置返回，不查询或操作真实守卫。
- 虚构应用没有登录、会话、钥匙串或网络功能。测试控制器只能关闭精确路径下的虚构进程；拒绝退出案例结束后的强制清理也只针对这些夹具。
- 正常更新必须经过真实签名校验、完整 App 交换、原生启动和新版本确认。没有把事务的验证或启动操作替换成成功返回。

覆盖正常升级、新版不确认启动时回退、旧版拒绝退出时保留、新版拒绝回退退出时保留两份、受损签名拒绝替换。启动明确指定新实例，防止系统复用另一路径下的同标识旧应用。

## 验收记录

本次结果在完成 Apple 公证和隔离测试后补齐；只有全部通过才发布。真实账号、会话、代理故障与钥匙串 ACL 继承不属于夹具验收。

历史 RC 包、票据和标签保持不可变。公开发布清单只包含版本、源码提交、分发散列和验证结论，不上传本机签名日志、私有路径或运行态快照。
