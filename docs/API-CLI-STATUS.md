# API 模式与 CLI 登录检查

当前源码构建：1.3.0-rc.6（20261030.6.10）。已有 Release 附件不会随源码提交自动更新。

## 桌面 API 模式

打开面板和刷新时重新读取桌面模式及已应用配置。首页直接显示 Magpie、CC Switch 或来源未确认；仅对已识别管理器提供打开入口。来源标记不代表网关健康，也不判断管理器上游是否使用订阅。

API 桌面下，保存的订阅档案不再标作当前桌面身份。订阅用量保留为缓存，订阅守护不接管 API 模式。

## CLI 检查与授权

终端行旁的检查入口读取官方 CLI 的 `auth status` 本地报告，不由切换器取出 token 请求远端 profile。报告已登录不等于在线凭据有效、与桌面身份已核验一致或正在运行的所有 CLI 都使用该配置。切换和同步仍经过原有的在线身份与备份验证。

后台凭据读取禁止授权弹窗；需要授权时保留未确认结果，不当作退出登录。主动检查调用的官方 CLI 自身仍受系统授权约束，不承诺永不弹窗。过期访问凭据显示为待 CLI 刷新，不自动刷新或改写登录。

信息弹层保留简短范围说明和检查时间，检查失败原因直接显示；账号缓存不能遮住失败原因。

## 验证边界

仅以虚构数据、临时目录和模拟 CLI 可执行程序验证。未用真实登录、钥匙串、会话或故障注入验收。真实系统授权持久性和连续刷新无弹窗仍需单独验证；网络过滤研究后端未接入产品。
