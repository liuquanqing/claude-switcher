## 安装策略

完整签名、公证后的 bundle 将安装到独立预览路径，例如 `/Applications/Claude Switcher Preview.app`。旧应用、旧助手及旧守卫启动路径继续保留，安装器不把旧 ad-hoc 助手混入已公证的新包，也不重签或修改新包内部文件。

验包必须确认正确的 Developer ID Application／Team、所有 Mach-O 的 Hardened Runtime、完整资源签名、app 自身 stapled ticket 和 Gatekeeper 接受状态。预览身份应由签名内的明确渠道／版本标记表达，不能只靠一个可改名的文件名。

通过验包后，才允许正常退出旧切换器 GUI，后台打开预览 GUI。不关闭 Claude、不终止已有 CLI、不修改守卫文件、配置、LaunchAgent 或登录项；旧守卫继续沿旧路径运行。旧 GUI 若拒绝退出，不强杀，不继续切换。

回滚只需正常退出预览 GUI、打开保留的旧 GUI。不搬回账户目录、不覆盖当前 CLI 凭据或真实会话，也不需要停止守卫。

## 假文件预检

本地预检工具和测试位于 `_qa/candidate-preview`，不属于生产安装器。6 项临时文件测试通过：
