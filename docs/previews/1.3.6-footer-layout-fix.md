# 1.3.6 底栏布局修正

RC2 已安装界面的底栏出现回退：时钟仍在，时间文字不可见；导入、刷新和设置靠左，退出前留出大片空白。

Kimi 仅修改两处布局约束：原生设置 Menu 本身固定为 28×28pt，正常时间摘要不再使用负布局优先级。保留左侧目录与时间、右侧导入/刷新/设置/退出，中间由弹性空白分隔。文案、账号区域、刷新行为及所有按钮动作保持原样。

正常状态显示相对时间，例如“4 分钟前”；这里表示最近成功取得额度的时间，不是点击刷新时间。部分失败继续显示时间及失败数量，完整采样日期仍在悬停说明中。

验证使用 `Store(demo: true)` 与内存虚构数据，将实际生产 Panel 放入原生 NSHostingView 离屏渲染，未启动已安装应用，也未读取真实账号、钥匙串或会话。500pt 宽下，中文与英文的正常、刷新中、长操作文字、部分失败、空数据共 10 个状态完成渲染并人工检查：时间可见，右侧操作不被挤走；英文长操作允许单行截断。

修复前离屏渲染未完整复现用户安装版“文字完全消失”的表现，因此根因判断来自布局约束与用户截图的结合；离屏结果不等于已安装版本的现场验收。

此次仅验证布局；原生菜单点击、键盘导航、辅助功能朗读未在本轮重新验收。未修改守卫、代理或网络配置；已发布 RC2 包不因本地源码修正而自动改变，需要重新打包后才能更新安装版本。
