# Claude Switcher 1.3.6 RC6

这是预览版，构建 20261104.6.1。适用于 Apple Silicon、macOS 13 或更新版本。

- **CLI 登录各自保留**：桌面切换保持默认 CLI 登录。可复制当前档案的独立目录命令，在终端使用原生 Claude Code 登录；原有终端和历史保留。兼容的默认登录同步仍需单独确认。
- **额度查询与登录分开**：后台和底栏只读 Claude Code 已产生的缓存，沿用原采样时间。需要新数据时可在原生 CLI 运行 `/usage`。本版不再因刷新额度启动续期或直接请求订阅额度接口。
- **桌面保护更稳定**：同一订阅桌面进程、独立的订阅模式标记未变时，普通配置保存会保留原有保护。模式标记失效或进程更换时，仍需重新确认。
- **状态更容易扫读**：正常时一行显示「桌面保护中 · SG」。空间不足或有异常时保留详细信息。
- **更新和菜单交互更简洁**：点击外部可收起菜单。手动检查更新时，只有发现新版才显示下载窗口。账号目录入口保留在底栏。

从旧版升级时，保护修复需要新版 App 和新版后台守卫一起生效。若启用了旧守卫，请选在 Claude Desktop 已退出时，按 [安装指南](../INSTALL.md#与原版共存或迁移) 完成交接。重新启用保护后，如果已有桌面尚未纳入，确认一次即可。
