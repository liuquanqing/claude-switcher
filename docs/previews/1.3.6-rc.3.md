# Claude Switcher 1.3.6 RC3

版本 `1.3.6-rc.3`，构建 `20261103.3.0`。本版接续 RC2，维持预览通道。

- 恢复底栏可见的相对采样时间，约束设置菜单宽度。
- 常用操作继续在右侧，账号目录收进设置；设置图标与相邻工具保持一致的默认颜色。
- 账号卡保留自身的缓存时间，精简为“缓存 · 8 小时前”；非新鲜数据不再只写“更新”。
- 失败、未请求、加载中、重置待确认分别保留提示；不改变账号卡高度和全局时间含义。

前端由 Kimi 实现，Codex 审查与虚构数据渲染复核。22 个中英文状态完成 500pt 原生离屏渲染；菜单点击、键盘和 VoiceOver 的现场复核未完成，不将静态渲染当作交互验收。

本轮不使用真实登录和会话作测试，不修改守卫或网络策略。发布前需完成当前提交的回归、Developer ID 签名、公证及最终安装包核验。交付结果另行记录。
