# 验证范围

本文说明正式版本 `v1.3.1` 已经用什么方式测过、测到了哪里，以及**还没有验证过什么**。通过测试不代表在所有环境下都安全或都能恢复。

## 测试原则

- 所有自动化测试只使用**虚构数据**、**注入的 worker**和**临时目录**。
- 维护者从未把真实登录、Keychain、账号目录或会话用于真实切号、断网、急停或会话迁移的验收。
- 构建和测试本身不会安装 App，不会注册后台服务，也不会做真实断网测试。

| 套件 | 运行方式 | 公开发布源码副本上的结果 |

| Core（`SwitcherCoreTests`） | `swift test`（或 `./build.sh test`） | 176 项通过 |

## 已覆盖的功能边界

以下行为在测试中用虚构输入验证过逻辑分支：

**网络门禁**
- 代理未连接、TUN 缺失、出口国家未知、国家不符、各域名出口不一致、配置无效：全部判定为不放行。
- trace 响应解析：只接受 HTTP 200 且唯一一个合法 `loc=` 字段的响应。
- 守卫回执缺失或过期（超过 30 秒）时判定为不可确认。

**CLI 凭据（Keychain / `.credentials.json`）**
- 只改写本工具管理的 OAuth 字段，保留其他字段。
- 冲突、拒绝读取、格式未知时停止操作。
- 备份失败会在退出或移动桌面目录之前被发现；写入失败后会回读并还原。
- 只处理默认保存的登录，与“正在运行的 CLI 进程”分开判断。

**桌面切换流程**
- 先核验再轮换目录；任一步失败都中止，并保持或还原原状态。
- API 模式或模式未知的桌面不会被自动纳入订阅保护。

**配置来源识别**
- 能识别 Magpie、CC Switch 的配置来源；仅根据非敏感配置标记判断来源，不输出或改写密钥。

**会话复制**
- 只处理已适配的桌面索引格式；默认只新增。
- 同一段会话可以验证时才做增量追加；备份、撤销、恢复都走日志记录。
- 检测到桌面或切换器仍在运行时拒绝操作。

**静默刷新**
- 已用原生演示窗口检查后台进行中、首次未核验和 API 模式的显示，全部为虚构数据。
- 桌面档案或模式变化会使旧结论失效；API 下单独核验身份不冒充桌面账号一致。
- 打开面板时只读本地状态；结果完成后一次性发布；检查过程中不会先降级；当前源码将主动检查入口放在终端状态行旁，读取官方 CLI 本地报告；ⓘ 只保留范围说明和检查时间。

**全局语言与复制界面**
- 中英切换同步首页、保护设置、已打开的复制窗口、原生菜单和提示。
- 旧语言偏好迁移使用隔离默认存储验证；无效值不改变当前语言，切换时保留未保存设置与搜索。
- 使用虚构会话走通选择、确认与取消、复制、备份、撤销及返回；完成摘要保留真实目标及新增/更新数量。
- 语言不会改变账号、CLI 观察或安全判定；复制指令保留命令、路径、指纹和 receipt 参数。
- 验证记录与截图见 [全局语言说明](GLOBAL-LANGUAGE.md)。

## 尚未验证

以下场景**没有**做过真实环境验收，请谨慎对待：

- 真实系统里的急停：守卫在真实断网或国家变化时关闭 Claude Desktop 的实际效果和时延。
- 真实账号的 A → B → A 往返切换，以及中途失败后的实际恢复。
- 真实 Keychain 权限弹窗、拒绝授权、钥匙串被锁定等情况。
- 菜单栏面板里的嵌套弹层（ⓘ 等）在不同 macOS 版本上的显示和焦点行为。
- VoiceOver 和其他辅助功能。
- Intel 上的实际交互与 universal 构建；云端编译不等于原生界面验收。
- Shadowrocket 和 `198.18.*` TUN 之外的代理或网络环境。
- 和原版 Claude Switcher、Magpie、CC Switch 同时运行时的实际交互。
- 上游 Claude Desktop 或 Claude Code 更新数据格式之后的兼容性。

## 已知局限

- 网络探测只是本程序对 `claude.ai`、`api.anthropic.com`、`claude.com` 的观察结果。它**不是防火墙**，也不能证明客户端每一条连接的出口。守卫约每 10 秒检查一次，在两次检查之间发生的变化不会被立即发现。
- 本工具**不承诺**账号安全、防封号，也不承诺所有失败情况都能恢复。
- 会话复制**不是**完整的云端聊天迁移，也不能让会话跨 CLI 账号自动接续。
- 切换 CLI 默认登录之后，已经在运行的 CLI 任务不会被强制停止，也不保证会立刻换成新账号。
