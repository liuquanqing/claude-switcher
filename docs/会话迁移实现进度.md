# 会话迁移实现进度

更新：2026-10-28。本轮用户已授权实现、隔离测试后再启用，并同步 GitLab；之后进一步要求先收敛 Kimi 网页交互。当前按这份交互稿统一原生接线，生产入口仍为 `sessionMigrationEnabled=false`，现用原版与已安装候选未替换。

## 已完成的隔离实现

- `SessionTransferService` 枚举来源/目标账号与组织空间，识别新增、同段增量、已有、领先、冲突及不支持的索引。多空间不猜默认；只读来源；不改聊天 JSONL、登录或 API 配置。
- 同段增量只更新已适配的进度字段，保留目标标题、未知字段与连接器。不同 CLI 段、缺少历史原文、显式账号/凭据绑定字段均阻止自动复制；网页中的模拟接续证明不等于正式引擎已支持跨段。
- 写前备份与回读、执行前身份/内容复核、独占新增、失败恢复与整批撤销预检已接入。外部新进展保留，恢复未确认继续锁定对应目标。
- 用户明确选择“保留现状并结束记录”只结束本软件日志，不写目标、不冒称已恢复；备份缺失或损坏时如实报告无法核对。
- 原生控制器已接真实文件引擎，演示入口只创建临时虚构目录；目标桌面在用时只要求用户自行退出，不停止桌面或 CLI。显示的会话身份变化会使原计划失效。
