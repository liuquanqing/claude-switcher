# 会话迁移实现进度

更新：2026-10-28。local.6 已更新到应用程序中的独立候选版，未启动，原版保留。全部验收只用独立虚构数据目录；真实会话、登录、代理与守卫未用于故障测试，也未自动交接守卫。

## 交付范围

- Kimi 完成原生单页清单、具体会话与路径、中文/英文、统一确认/备份/指令模态；返回按钮与窗口红点回账号面板，同一 Store 缓存控制器，未完成记录不会因为返回而消失。
- 默认只新增，涉及已有会话更新才确认。只支持已适配的同一 CLI 段增量：保留目标标题、未知字段和连接器，只改允许的进度字段。不同段续接、缺失原文、无法确认的账号/凭据绑定仍阻止自动复制。
- 源/目标、账号标记、目录身份和所选内容复核；自动备份与回读、独占新增、失败恢复、整批撤销预检。外部新进展保留，恢复未确认就锁定该目标。JSONL 原文不改写。
- 备份摘要先核对实际文件。用户显式“保留现状并结束记录”只结束日志，不写目标、不冒称已恢复；备份缺失或损坏如实显示。
- “复制给 Claude”只导出本地请求与操作指令，不自动执行或发送；附带 `ClaudeSessionTransfer` helper，共用同一服务和事务。详见[备用命令说明](会话复制备用命令.md)。

## 边界

这是已安装的独立候选更新，入口已开放，但没有启动候选或进行真实账号迁移验收。未执行真实断网、节点切换、急停、账号回切、会话迁移或新守卫注册。操作系统崩溃/断电仍只有合成中断日志测试，不声称跨文件原子性。更广格式和跨 CLI 段自动接续另行适配。

前阶段网页稿 22 组浏览器检查保留为交互设计证据，不替代本轮引擎与原生验证。原生前端与文案由 Kimi 编写，Codex 负责后端、接线协议与审核测试。

## 选择与安装的后续精简

前端由 Kimi 根据用户反馈独立评估：选中行去掉橙色竖线/棕色整块，改中性高亮；名称统一为“导入”，主操作“开始导入”，次级“复制指令…”先打开只读预览。已选数量仅在底部显示，筛选外选择明确计数。

首次有效载入或切换来源/目标空间时默认选缺少项，不默认选择已有更新；手动取消、普通刷新、重进或完成后不会自动再次勾选。三态全选仅操作当前搜索范围的可导入项。
