# 安装与迁移

本轮已另装独立候选，未替换原版、未启动或接管旧守卫，详见[当前安装状态](候选安装与验证策略.md)。下面“首次安装”为原替换流程，本次未执行；服务交接等待用户选择。守卫/急停不安排真实账号故障注入。

## 首次安装

1. 完成 `swift test` 和 `./build.sh`。
2. 保存工作并退出 Claude，以及旧的 Claude Switcher 界面。
3. 运行 `./build.sh install`。旧 App 会备份至当前用户的 `Library/Application Support/ClaudeSwitcher/install-backups/`。
4. 打开 `/Applications/Claude Switcher.app`，选择目标国家与代理模式，点击“启用保护”。启用前不自动注册守卫或登录项。
5. 等待独立守卫生成有效回执，再使用“检查并打开”或账号切换。已有订阅桌面不会自动认领；确认模式后可用“保护当前桌面”，或保存工作退出桌面后从本入口启动。

未识别 TUN、国家未知、国家不符或守卫没有新回执时会拒绝打开。错误页面的 HTTP 403/401 不能作为账号可用证明；本产品也不把匿名探测替代真实账号验收。

配置与回执位于 `~/Library/Application Support/ClaudeSwitcher/`。用户级后台任务为 `~/Library/LaunchAgents/dev.claudeswitcher.guard.plist`。守卫直接使用当前 App 包内的 `ClaudeGuard`，不得单独移动 App 包里的组件。

## 从 YOURSJEYO 旧保镖迁移

新守卫不会静默卸载旧服务。检测到 `/Library/LaunchDaemons/local.claude-bodyguard.plist` 时拒绝同时启用。

1. 保存当前工作并完全退出 Claude，保留全部账号数据。
2. 核对旧服务标签为 `local.claude-bodyguard` 和 `local.tz-watchdog`；它们来自此前安装的旧切换器。
3. 可以先运行 `scripts/migrate-legacy-guard.sh --dry-run` 查看计划；确认可中断后再明确执行 `scripts/migrate-legacy-guard.sh`。实际脚本需要管理员授权，只卸载这两个系统任务，把 plist 移到 root 所有、权限 700 的时间戳备份目录；不删除旧脚本、账号快照、终端登录或会话。
4. 在新应用中明确启用保护，确认守卫回执正常，再打开 Claude。

迁移期间 Claude 必须保持关闭，避免保护交接空档。脚本不会恢复或修改之前设置的语言、地区、时区、IPv6 或代理规则。旧切换器的 `~/.claude-switcher/accounts/` 不导入、不改结构、不删除；其迁移需要单独核对。

回退时先停止新保护，再从脚本打印的备份目录恢复原 plist，并以管理员身份重新 bootstrap 原服务。回退仍应在 Claude 已退出时进行，避免两套守卫同时运行。

## 退出与停止

- 电源按钮或 ⌘Q：只退出界面，独立守卫仍运行。
- “停止保护”：明确确认后关闭本应用的守卫并移除其用户级任务。停止后本应用不会再放行打开 Claude，直到重新启用。
- 切换、复制或保护配置正在写入时暂不退出，避免中断数据操作。
- 异常网络下守卫仅对已确认归属的订阅桌面先请求退出，约两秒后仍未退出会强制终止；该桌面的工作可能中断。CLI 任务不被终止，仍需正确的网络路由。
- API/未知配置、未确认的外部桌面不自动纳入。PID、启动时间或配置代次变化后需要重新确认；当前配置是订阅不等于已有进程必然使用订阅。

## CLI 与 API 交接

正常切换会核验并同步目标已保存的默认 CLI 登录。没有目标登录时显示需要登录；无法确认的旧备份不会被猜测恢复。CLI 准备阶段失败时，用户可明确选择仅切桌面，CLI 保持原样；之后可核验并同步，或在官方 CLI 完成登录。读回或还原失败不自动继续下一次切换。

若旧备份过期且未验证，可先使用原切换器切到对应档案，在官方 CLI 登录并按原工具流程保存，再回候选版核验；不手动删除钥匙串。本轮没有执行这个真实账号流程。

Magpie / CC Switch 显示的是生效配置匹配来源，不是“正在代理”或网关健康。只打开白名单应用，不改密钥、模型或模式。退出 API 接管应在原工具的模式/提供方设置中操作；只退出管理器应用可能仍保留 Claude 的 API 配置。CLI 参考工具 CCSwitcher 与 API 管理器 CC Switch 是两个项目。

## 卸载

先从界面停止保护，或执行：

```sh
scripts/stop-protection.sh '/Applications/Claude Switcher.app'
```

确认后台任务卸载后，再把 App 移至废纸篓。账号目录、钥匙串与聊天历史保留；本脚本没有清理这些数据的选项。

## 开发隔离

不要为了测试执行真实安装或迁移。演示模式用假账号及内存状态，不访问真实钥匙串、账号目录或网络；原型会话迁移在本轮不可执行。

```sh
'build/Claude Switcher.app/Contents/MacOS/ClaudeSwitcher' --snapshot _qa/panel.png --demo
```

没有 `--demo` 的截图命令会拒绝运行。正式账号切换、真实断网急停、订阅/API 迁移与 x86_64 真机验收均单独记录，不由模拟测试推断。
